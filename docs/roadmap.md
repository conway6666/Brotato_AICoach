# Brotato AI Coach Roadmap

## 1. 项目定位

Brotato AI Coach 是一个面向《土豆兄弟》的 AI 游戏导师 Mod 原型。当前阶段不追求通用多游戏伴侣平台，而是先验证一个高价值、低剧透、强数值决策场景：大块头（Chunky）商店阶段导师。

核心价值是帮助玩家在商店购买、属性选择和构筑转型时获得及时、克制、可信的建议，降低因非线性数值收益带来的选择困难和暴毙焦虑。

## 2. 当前目标游戏与优先级

| 游戏 | 类型 | 适配优先级 | 说明 |
| --- | --- | --- | --- |
| Brotato / 土豆兄弟 | Roguelike / 数值构筑 | P0 | 商店决策高频、数值机制明确、剧透风险低，适合作为 AI 导师实验原型。 |
| RPG 类游戏 | 信息差 / 剧情探索 | P3 | 防剧透价值高，但剧情进度约束和知识边界复杂，不进入首期。 |

## 3. 游戏适配度评估

| 维度 | 评分 | 说明 |
| --- | --- | --- |
| 数据可采集性 | 4/5 | 商店、角色、属性、武器和波次数据结构相对明确；具体 Mod Hook 方案待验证。 |
| 决策复杂度 | 5/5 | 商店购买、属性成长、武器组合和角色机制存在明显非线性收益。 |
| 攻略知识价值 | 4/5 | 社区流派和角色经验可转化为波次-属性及格线、避坑规则和构筑方向。 |
| 实时辅助价值 | 4/5 | 商店阶段是天然暂停点，适合轻量提示且不破坏战斗节奏。 |
| Mod 风险 | 3/5 | 主要风险来自数据抓取稳定性、版本更新和 UI 注入方式。 |
| 综合优先级 | P0 | 适合作为首个单游戏 AI 导师验证对象。 |

## 4. Roadmap

| Phase | 目标 | Feature 候选 | 验证方式 | 不做什么 |
| --- | --- | --- | --- | --- |
| Phase 0 | 验证 Chunky 数值决策是否可被确定性工具可靠计算 | Chunky 机制建模、EHP/DPS/ROI 计算、商店候选排序 | 给定固定输入样例，稳定识别 `%伤害` 无效、生命值双重收益和高风险购买 | 不接入完整 UI、不做多角色、不做 RAG |
| Phase 1 | 完成单角色商店阶段 MVP | `chunky-shop-advisor`、一键扫描、3 行以内建议气泡、快捷追问入口 | 玩家在商店按快捷键后获得可解释购买/跳过建议 | 不做战斗中实时提示、不自动操作 |
| Phase 2 | 扩展知识库与更多 Brotato 场景 | 多角色策略模板、波次-属性及格线、社区构筑知识库 | 建议能随波次和已有装备动态修正 | 不做跨游戏抽象框架 |
| Phase 3 | 优化陪伴体验与成本控制 | 语气人格、追问聊天、缓存、降级提示 | 提示更自然、延迟和 API 成本可控 | 不做语音陪玩和长剧情 Companion |
| Phase 4 | 评估多游戏适配 | 游戏适配接口、数据契约、剧透策略分层 | 新游戏接入成本可预测 | 不承诺所有游戏通用 |

## 5. Feature 候选池

| Feature | 所属 Phase | 用户价值 | 优先级 | 交给 game-pm 的输入 |
| --- | --- | --- | --- | --- |
| `chunky-shop-advisor` | Phase 0-1 | 在 Chunky 商店阶段给出购买、跳过和转型建议 | P0 | 输入 Wave、角色、属性、武器、商店物品；输出排序、理由、风险和 3 行建议。 |
| `brotato-stat-calculator` | Phase 0 | 用确定性算法计算 EHP、DPS、ROI，降低 LLM 数值幻觉 | P0 | 定义计算公式、输入字段、输出结构和测试样例。 |
| `minimal-advice-bubble` | Phase 1 | 用极简气泡保持心流，避免复杂聊天框打断游戏 | P1 | 最多 3 行建议、可选追问标签、失败降级文案。 |
| `brotato-knowledge-base` | Phase 2 | 把角色、物品、武器和社区流派转为可检索知识 | P2 | 数据来源、JSON schema、波次-属性及格线。 |

## 6. 当前范围边界

首期只做 Brotato / Chunky / 商店阶段 / 数值正确性验证。

当前版本明确不做：

- RPG 游戏适配和剧情防剧透系统。
- Brotato 多角色完整覆盖。
- 战斗中实时提示。
- 自动购买、自动加点或任何代替玩家操作的能力。
- 完整 Wiki/RAG 问答。
- 多游戏通用框架。
- 语音陪玩或长期情感陪伴系统。
